# Green Accent Color Reference

This document lists the **green** color codes used as the primary accent in the Cassava Digital frontend. The project uses Tailwind CSS default palette (no custom theme).

---

## Green (primary accent)

Used for nav highlights, buttons, links, and accents across the site.

| Tailwind class   | Hex       | Usage in project                          |
|------------------|-----------|-------------------------------------------|
| `green-50`       | `#f0fdf4` | Backgrounds (e.g. badges, light areas)    |
| `green-100`      | `#dcfce7` | Soft backgrounds, step numbers            |
| `green-200`      | `#bbf7d0` | Borders, subtle backgrounds, hover        |
| `green-300`      | `#86efac` | Nav hover, decorative lines               |
| `green-400`      | `#4ade80` | **Primary green** – brand, buttons, icons|
| `green-500`      | `#22c55e` | Buttons, borders, focus rings             |
| `green-600`      | `#16a34a` | Taglines, links, darker accents           |
| `green-700`      | `#15803d` | Text on light green (e.g. badge text)     |

**Hex codes (copy-paste):**

